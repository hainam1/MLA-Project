# Final Report Workspace

Write the final report from verified artifacts in `outputs/`. The planned sections are Introduction,
Background, Dataset, Data Audit and Preprocessing, Feature Engineering, Models and ML Pipeline,
Experimental Setup, Evaluation Metrics, Results, Analysis and Interpretation, Error Analysis,
Limitations and Responsible Use, LLM Disclosure, and Conclusion.

Do not manually copy illustrative or historical numbers into the report. Every reported value must
match a saved result file from the frozen experiment.
